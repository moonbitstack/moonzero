async fn[T] Sql::transact(self : Sql, body : async (Sql) -> T) -> T

itemRun body inside a transaction: it commits when the body returns and rolls back when it raises, so a failure halfway through leaves nothing behind. The body receives a Sql bound to the same driver — the driver is the transaction, in this contract — so a nested call cannot silently start a second one.
