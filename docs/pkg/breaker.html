01 / RESILIENCE

breaker

The Google SRE client-side throttling breaker over moonward's: it reads the last ten seconds of outcomes and sheds a computed fraction of calls rather than opening, and the breaker middleware answers 503 for a shed one.

fn breaker( b : @breaker.Breaker, refusal~ : Refusal = unavailable) -> Middleware

fnCircuit-breaker middleware: gate each HTTP request through a shared Breaker. An admitted request's outbound HttpResponseStart status is observed — a 5xx settles its promise as a failure, anything else as a success, and that is what feeds the window. A shed request is answered 503 Service Unavailable without the wrapped app running. Non-HTTP scopes pass through untouched. The promise starts out a failure and only the observed status makes it a success, on a defer — the same shape doReq uses, so a handler that raises or is cancelled before answering counts against the window instead of quietly not counting at all.
