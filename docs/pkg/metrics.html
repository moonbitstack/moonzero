metrics

Two Prometheus families over the process registry: a duration histogram and a code counter, labelled path, method and code — three labels, so a dashboard can select on any one of them.

struct ServerMetrics

structThe request metrics an HTTP service exposes: http_server_requests_duration_ms and http_server_requests_code_total, each partitioned by path, method and code. Held by the caller so it can be scraped after serving, and shared with RestEngine so the prometheus layer and the /metrics route read one set.

fnMetrics middleware: time each HTTP request on the shared clock and, when the response starts, count it under its path, method and status and record its latency in milliseconds.
