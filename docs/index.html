03 / CONFIGURED, NOT CODED

The service is a document

etc/orders.yaml
Name: orders-api
Host: 0.0.0.0
Port: 12000
Middlewares:
  Breaker: true
  Shedding: true
  Gunzip: true
Breaker:
  CpuThreshold: 800

read at load · refused if wrong · defaulted if absent

Middlewares.Breaker
The chain is assembled from these flags — a flag with nothing behind it changes no layer.
Breaker.CpuThreshold
A thousandth of the CPU reading: 800 is 80%. The shedder reads the same number.
Port
One number for the listener. The host that runs the application owns the socket.
